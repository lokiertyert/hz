# Объектная модель — Система управления доступом БЦ

Конкретные экземпляры (объекты) предметной области и связи между ними.
Формат **Mermaid** (рендерится на GitHub).

Объект записан как `имяОбъекта : Класс` с текущими значениями атрибутов.

---

## 1. Обзорная карта объектов

```mermaid
flowchart TB
    subgraph Тенанты
        T1["tenant_romashka : Tenant\nname = «Ромашка»"]
        T2["tenant_vektor : Tenant\nname = «Вектор»"]
    end

    subgraph Субъекты
        E1["emp_ivanov : Employee\nИванов И.И."]
        E2["emp_petrova : Employee\nПетрова А.С."]
        E3["emp_sidorov : Employee\nСидоров П.П."]
        G1["guest_kuznetsov : Guest\nКузнецов Д.М."]
        G2["guest_orlova : Guest\nОрлова Е.В."]
    end

    subgraph Пропуска
        P1["pass_1001 : Pass\nACTIVE, EMPLOYEE"]
        P2["pass_1002 : Pass\nACTIVE, EMPLOYEE"]
        P3["pass_1003 : Pass\nBLOCKED, EMPLOYEE"]
        P4["pass_2001 : Pass\nACTIVE, GUEST"]
        P5["pass_2002 : Pass\nEXPIRED, GUEST"]
    end

    subgraph Пользователи
        U1["usr_admin : Administrator\nАдминистратор"]
        U2["usr_guard : SecurityGuard\nОхранник"]
        U3["usr_director : Director\nДиректор"]
        U4["usr_tm : TenantManager\nМенеджер «Ромашка»"]
    end

    subgraph Зоны
        Z1["zone_lobby : Zone\nГлавный вход"]
        Z2["zone_parking : Zone\nПарковка"]
        Z3["zone_server : Zone\nСерверная"]
    end

    subgraph Инфраструктура
        TS1["turnstile_a : Turnstile\nВход A"]
        L1["log_5001 : AccessLog\nGRANTED"]
        L2["log_5002 : AccessLog\nDENIED_BLOCKED"]
        B1["ban_9001 : BanRecord\nСидоров, 3 дня"]
    end

    T1 --> E1
    T1 --> E2
    T2 --> E3
    E2 -.->|invite| G1
    E1 --> P1
    E3 --> P3
    T2 -.->|holds| G2
    G1 --> P4
    G2 --> P5
    P1 --> Z1
    P1 --> Z2
    P3 --> Z1
    P1 -.->|logged| L1
    P3 -.->|logged| L2
    B1 --> E3
    TS1 --> P1
    U2 --> B1
    U3 -.-> B1
    U1 --> P3
    U4 --> P1
```

## 2. Объект «пропуск» и его окружение (детально)

```mermaid
flowchart LR
    subgraph Пропуск["pass_1001 : Pass"]
        A1["id = 1001"]
        A2["number = «AA-1001»"]
        A3["type = EMPLOYEE"]
        A4["status = ACTIVE"]
        A5["validFrom = 2026-01-01"]
        A6["validTo = 2026-12-31"]
        A7["blockReason = —"]
    end

    E["emp_ivanov : Employee\nИванов И.И."]
    T["tenant_romashka : Tenant\n«Ромашка»"]
    Z1["zone_lobby : Zone\nГлавный вход"]
    Z2["zone_parking : Zone\nПарковка"]
    U["usr_admin : Administrator\nАдминистратор"]
    L["log_5001 : AccessLog\nGRANTED"]

    E -->|владелец| Пропуск
    E -->|работает в| T
    Пропуск -->|доступ| Z1
    Пропуск -->|доступ| Z2
    U -->|управляет| Пропуск
    Пропуск -.->|зафиксирован проход| L
```

## 3. Сценарий: заблокированный пропуск Сидорова

```mermaid
flowchart TB
    E["emp_sidorov : Employee\nСидоров П.П."]
    T["tenant_vektor : Tenant\n«Вектор»"]
    P["pass_1003 : Pass\nstatus = BLOCKED\nblockReason = «увольнение»"]
    B["ban_9001 : BanRecord\nreason = «нарушение»\nisPermanent = false"]
    U["usr_admin : Administrator"]
    L["log_5002 : AccessLog\nresult = DENIED_BLOCKED"]
    TS["turnstile_a : Turnstile\nВход A"]

    E --> T
    E --> P
    U -->|деактивировал| P
    U -.->|причина| P
    P --> TS
    TS -.-> L
    B --> E
```

## 4. Гостевой визит (объекты одного дня)

```mermaid
flowchart LR
    E["emp_petrova : Employee\nПетрова А.С."]
    G["guest_kuznetsov : Guest\nКузнецов Д.М.\nvisitDate = 2026-10-22"]
    P["pass_2001 : Pass\nACTIVE, GUEST\nvalidTo = 2026-10-22 18:00"]
    Z["zone_lobby : Zone\nГлавный вход"]
    L["log_5003 : AccessLog\nGRANTED"]
    TS["turnstile_a : Turnstile"]

    E -->|приглашает| G
    G --> P
    P --> Z
    P --> TS
    TS -.-> L
```

## 5. Роли-пользователи и их объекты-действия

```mermaid
flowchart TB
    U1["usr_admin : Administrator"] -->|создаёт/меняет/деактивирует| PX["pass_1001 … pass_N : Pass"]
    U2["usr_guard : SecurityGuard"] -->|временный бан| BX["ban_* : BanRecord"]
    U2 -->|проверка| PX
    U3["usr_director : Director"] -->|бан кого угодно| BX
    U3 -->|проход| PX
    U4["usr_tm : TenantManager"] -->|заявка на пропуск| PX
    U5["emp_ivanov : Employee"] -->|проход| PX
    U6["guest_kuznetsov : Guest"] -->|проход| PX
```
