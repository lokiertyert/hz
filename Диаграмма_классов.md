# Диаграмма классов — Система управления доступом БЦ

Модель предметной области и роли. Формат **Mermaid** (рендерится на GitHub).

---

## 1. Диаграмма классов (основная модель)

```mermaid
classDiagram
    class Pass {
        +UUID id
        +String number
        +PassType type
        +PassStatus status
        +Date validFrom
        +Date validTo
        +String blockReason
        +create()
        +update()
        +deactivate(reason)
    }

    class Subject {
        <<abstract>>
        +UUID id
        +String fullName
        +SubjectKind kind
    }

    class Employee {
        +UUID id
        +String position
    }

    class Guest {
        +UUID id
        +Date visitDate
        +String hostInfo
    }

    class Tenant {
        +UUID id
        +String name
        +String contacts
        +closeContract()
    }

    class Zone {
        +UUID id
        +String name
        +ZoneKind kind
    }

    class User {
        <<abstract>>
        +UUID id
        +String login
        +Role role
    }

    class TenantManager
    class SecurityGuard
    class Administrator
    class Director

    class AccessLog {
        +UUID id
        +DateTime timestamp
        +AccessResult result
    }

    class BanRecord {
        +UUID id
        +Date from
        +Date to
        +String reason
        +isPermanent
    }

    class Turnstile {
        +UUID id
        +String location
        +checkPass(pass)
    }

    Subject <|-- Employee
    Subject <|-- Guest
    User <|-- TenantManager
    User <|-- SecurityGuard
    User <|-- Administrator
    User <|-- Director

    Tenant "1" --> "*" Employee : employs
    Subject "1" --> "*" Pass : owns
    Pass "*" --> "*" Zone : grants access
    TenantManager "1" --> "*" Pass : requests
    Administrator "1" --> "*" Pass : manages
    AccessLog "*" --> "1" Pass : logged for
    BanRecord "*" --> "1" Subject : bans
    Director "1" --> "*" BanRecord : issues
    SecurityGuard "1" --> "*" BanRecord : issues
    Turnstile "1" --> "*" Pass : verifies
    BanRecord "1" --> "*" Zone : scoped to
```
